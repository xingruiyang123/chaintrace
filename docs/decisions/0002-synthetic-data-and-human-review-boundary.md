# ADR 0002：仅用合成数据，匹配结果必须人工复核

- 日期：2026-11-09
- 状态：已采纳

## 决定

仓库中的 fixture 和示例必须明确标记 `is_simulated=true`。算法只输出可解释候选，不自动确认人员身份、账户归属或资金转移关系；结果状态维持待复核/争议状态。

## 原因

当前没有经授权的真实案件数据和业务标定真值。金额、时间、资产、方向或标识的相似度只能用于辅助排序；把它写成准确率、资金流向或身份结论会超出证据支持范围。

## 后续变化

若未来需要使用真实业务数据，必须另行完成授权、脱敏、访问控制、审计、数据保留和独立验证设计；不得把真实数据放进公开 CI fixture。
