# ADR 0001：采用私有 monorepo 作为团队协作基线

- 日期：2026-11-09
- 状态：已采纳为首次迁移方案

## 决定

将核心算法、Electron/React UI、Python 桥接、合成数据、测试、SQL 和技术文档放在同一私有 GitHub 仓库中；通过 PR 和路径化 CI 协同维护。

## 原因

桌面服务直接导入冻结算法，UI、桥接和测试共享样例及导出契约。统一提交历史有利于同步审查接口变化，五人团队也无需跨仓库版本协调。

## 约束

- 不提交真实案件资料、身份信息、密钥或本机配置。
- 不提交生成物和便携程序；经过验收的 Windows 构建物另放私有 Release。
- 不附加开源许可证，仓库保持私有。
- 首次 CI 未运行前不宣称自动化验收通过。
